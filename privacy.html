Privacy Policy

Last updated: 2026-09-17

This application is a personal, single-user tool that uses rclone to back up the owner's own files to the owner's own Google Drive account. It is used only by the account owner.

What it accesses

With the owner's authorization, the application accesses the owner's Google Drive solely to read and write the owner's own files for backup and restore.

What it does not do

It does not collect, store, sell, share, or transmit any personal data to any third party. There are no other users. No data is used for advertising or analytics. Google user data accessed by this app is used only to provide the backup functionality described above and is not shared with anyone.

Data retention

Backed-up files remain in the owner's own Google Drive under the owner's control and can be deleted by the owner at any time.
